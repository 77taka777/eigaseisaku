# 未来制作録

映画と舞台の制作現場を、3人の案内役と5つの問いから学ぶ日本語サイトです。
映画会社が社会貢献活動として公開し、社外の人が制作の仕事を無料で学べる形を想定しています。
導入前に決めることは `CSR-GUIDE.md` にまとめています。

## 内容

- 主催者名、社会貢献活動としての趣旨、個人情報の扱いを示す表示（`content/program.ts` で設定）
- 学びのねらい、対象、所要時間と、「作品ができるまで」の全体像
- 学習前後の自己評価による、理解の変化のふり返り
- 地点ごとの職業紹介（どんな仕事、向いている人、なるには）
- 自分で試せる体験課題「やってみよう」と、話し合いの問い
- 名前を入れて印刷できる修了証
- 読みがなつきの用語集
- 先生・主催者向けの手引き（`/teacher`、50分の進行案つき、印刷対応）
- 回答の途中経過を端末の中だけに保存（名前や連絡先は集めません）
- 3人のオリジナル案内役キャラクター
- 撮影・照明・音響・舞台転換・編集を巡る5地点の「制作軌道図」
- 地点ごとに異なる5つの3択問題と回答状況の記録
- 回答結果、判断理由、実際の現場手順、確認項目まで読める詳しい解説
- 回答済みの地点同士をつなぐ軌道演出と、判断成功・要確認の表示
- 5問終了後、正解数に応じて変わるS・A・B・C・D・Eの総合ランク、称号、講評
- 完成記録からの回答見直しと、最初からの再挑戦
- 光跡、回転軌道、移動する案内役、走査線などのアニメーション
- パソコンとスマートフォンに対応
- 動きを減らす端末設定に対応
- 読み上げ用の進捗通知と、次の地点へ移動したときのキーボードフォーカス
- 日本語のみの画面構成

## デザインについて

1980年代のレトロフューチャー映画を広く着想源にしながら、光跡、遠近グリッド、同心円、抽象化した撮影機材で独自に構成しています。5地点の軌道図と3人の案内役も、このサイトのために独自制作したものです。既存映画や既存サイトのロゴ、地図、車、人物、固有小道具、物語設定は使用していません。

見出しには、SIL Open Font License 1.1で提供されている「Dela Gothic One」を同梱しています。ライセンス本文は `public/assets/font/OFL-DelaGothicOne.txt`、配布元は [Google Fonts](https://github.com/google/fonts/tree/main/ofl/delagothicone) です。

## 起動

```bash
pnpm install
pnpm dev
```

ブラウザで `http://localhost:3000/` を開いてください。

本番用の確認：

```bash
pnpm build
```

## 主な編集箇所

- `content/program.ts`：主催者名、部署、趣旨文、監修者、修了証、効果測定の送信先
- `content/stages.ts`：5地点の問い、解説、職業紹介、体験課題、話し合いの問い、現場の声
- `content/glossary.ts`：用語集
- `app/page.tsx`：画面の構成と操作
- `app/teacher/page.tsx`：先生・主催者向けの手引き
- `lib/report.ts`：匿名の効果測定（送信先が空の間は何も送りません）
- `app/globals.css`：未来映画風の画面設計、書体、キャラクター表示、軌道図、アニメーション、レスポンシブ表示
- `app/layout.tsx`：ページ情報と共有画像の設定
- `public/og.png`：共有用画像
- `public/assets/crew/`：3人の案内役キャラクター画像
- `public/assets/font/`：見出し書体とライセンス
- `ASSET-PROMPTS.md`：共有用画像とキャラクター画像の生成記録

このサイトは自主制作のデモです。実在する映画、舞台作品、企業、登場人物とは関係ありません。
画面の「〇〇映画株式会社」はサンプル表記です。
